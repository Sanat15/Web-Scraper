Rating: 4/5

Personal Reaction- This book is a really cute book and I like how it teaches a lesson about being a good friend. This would be a good book for a student to read around Easter. This is a good transitional book because it uses complete sentences and a variety of punctuation. 

Read aloud- This book does not have any beneficial value to read it aloud because it lacks a strong storyline.

Independent reading- This is a very good transitional book because it has complete sentences, multiple sentences per page, good punctuation, uses good words, and is a little longer then the beginning to read books. 

Literary elements- This book lacks a strong plot, theme, characterization, setting, conflict, and tone, which does not make it a good book for teaching any of these elements. This book does share a story about Easter egg hunting and being a good friend, but the story does lack strong literary elements. 

Other- A nice thing about this book is that has a page of matching and a page for missing letters, which will challenge readers.
